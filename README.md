## 十一、单位解析规则
导入 `units_*.set` 时，解析器处理三种格式：

**格式 1：标准格式**
```
{"su-25sm_at"
    ("squad_vehicle" side(sov) ...)
    {cost 12}{action "..."}
}
```
名称来自 `{"..."}`，分类（squad_type）来自 `("..."` 中第一个引号词。

**格式 2：Conquest 格式（仅 side）**
```
("squad_with4types_conquest" side(sov) name(squad_conscript_con) ...)
```
名称 = `name(squad_conscript_con) + (sov)` → `squad_conscript_con(sov)`
分类 = 第一个引号词。

**格式 3：Conquest 格式（side + nation）**
```
("squad_with4types_conquest_warsaw" nation(gdr) side(sov) name(squad_kda) ...)
```
名称优先使用 `nation` 后缀 → `squad_kda(gdr)`，`side` 字段仍记录为 `sov`。

**科技单位**: `unit_research_*.set` 中的 `{ tech ... }` 条目归入「🔬 科技单位」，`unit_type = "tech"`。

### 1. Launch the Application
Run `Research_Tree_Generator_v2.2.2.exe` (or `python main.py` from source). The

- **Left Panel**: Unit list (grouped by squad type, with category filter)
- **Center Canvas**: Tech tree visual editing area (grid alignment, zooming, middle-button panning)
- **Right Panel**: Property editor (modify unit parameters and prerequisites)

### 2. Import Files
- **Import units_*.set**: Load complete unit definition file; supports importing **multiple files simultaneously** (stacking mode), duplicates are auto-skipped
- **Import unit_research_*.set**: Load tech tree structure file; only one file can be imported, new imports overwrite previous data

**Single-click a node** to edit: Costs (0-1000), Position X/Y (0.1 step), Requires (prerequisite names). Press **Enter** or click another node to save.

1. Right-click child node → **🔗 Select Parent Unit**
2. Crosshair cursor appears, click the target parent node
3. Connection line is generated automatically

> Multiple parents supported: repeat the process for multiple prerequisites.

## 5. Delete and Undo

### Delete a Node
Right-click the target node → **🗑️ Delete Node**. Deleting a parent automatically
removes that reference from all of its children, and the connecting lines disappear
as well.

### Undo and Redo
**Undo (Ctrl+Z)** — up to 50 steps:
- ✅ Add unit
- ✅ Delete unit (restores children's `requires` references)
- ✅ Move unit (restores previous coordinates)

**Redo (Ctrl+Y)** — after undoing, press Ctrl+Y or use **Edit → Redo** to re-apply.
Performing a new action clears the redo history.

## 6. Save and Export

- Unsaved changes prompt on close

### ✨ New Features / 新增功能
- ✅ **Redo functionality restored / 重做功能恢复**: `Ctrl+Y` and the **Edit → Redo** menu item now work. ### 🐛 Bug Fixes / Bug 修复
- ✅ **Redo chain could never survive an undo / 重做链被撤销自身破坏**: Undoing an *add* internally deletes the node, which pushed a new `DELETE_UNIT` action and cleared the redo stack — so `Ctrl+Y` was dead even if implemented. `TechTreeCanvas.on_item_deleted()` now takes `record_undo=False` for internal calls / 撤销"添加"时内部删除会压入新动作并清空重做栈，导致重做永远不可用
- ✅ **Non-atomic export could corrupt mod source files / 非原子导出会损坏源文件**: The exporter wrote directly with `open(path, 'w')`, and the output path is usually the original file — a mid-write failure destroyed the user's `.set`. Now writes to a temp file and atomically `os.replace()`s it, keeping a `.bak` of the previous version / 导出改为"临时文件 + 原子替换"，并自动生成 `.bak` 备份，写失败时原文件保持完好
- ✅ **`{positions}` block corrupted on save / `{positions}` 块被破坏**: Lines like `{"unit" x y}` inside a `{positions}` block matched the unit-line parser, so units that existed only there were rewritten as full `requires/costs/position` lines, breaking the block syntax. The exporter now preserves the whole block verbatim / positions 块内的单位行不再被误判改写
- ✅ **Language switch silently discarded unsaved work / 切换语言静默丢失数据**: `switch_language()` called `os.execl()` directly, bypassing `closeEvent` and throwing away unsaved changes. It now prompts Save / Discard / Cancel first, and the frozen-exe restart path was fixed / 切换语言前先提示保存，打包运行的自身重启参数也已修正

**Bug Fixes, Performance & Cleanup / 缺陷修复、性能与清理**

### 🐛 Bug Fixes / Bug 修复
- ✅ **Undo fix / 撤销修复**: The property panel's Costs change could never be undone — `MODIFY_PROPERTY` was pushed with key `property_name` but read back as `property`, raising `KeyError` that was silently swallowed. Now both key names are accepted / 修复属性面板修改 Costs 后按 Ctrl+Z 必然失败的问题（压栈写 `property_name`、读取却是 `property`，KeyError 被静默吞掉）
- ✅ **Save-on-close fix / 关闭时保存修复**: Choosing "Save" on exit closed the window even if you then cancelled the save dialog, silently losing data. `save_tech_tree()` now returns a status and the window only closes on real success. The unsaved-changes flag is also reset after a successful save (previously it prompted "unsaved" on every close) / 修复退出时选"保存"却在保存对话框点取消仍会关窗导致数据丢失；保存成功后正确复位未保存标记
- ✅ **Flask icon fix / 烧瓶图标修复**: `update_from_unit()` compared a unit's type with itself, so switching a unit between normal and `tech` never updated the flask icon / 修复单位类型在普通与 tech 间切换时烧瓶图标不更新的恒假分支
- ✅ **Grid snapping fix / 网格吸附修复**: Snapping rounded in *pixel* space, so a unit at logical 0.35 became 139.99999999999997px and `round(3.4999…)` produced **0.3** instead of 0.4 — dragging to 0.35 jumped backwards. Snapping now rounds in *logical* space / 修复网格吸附在边界上因浮点噪声方向不可预测的问题（拖到 0.35 会被吸附到 0.3）
- ✅ **Silent data drift fix / 静默数据偏移修复**: Clicking a node used to snap it to the grid on mouse-press without writing back to `unit.position_*` and without an undo record — the canvas could show 0.4 while the data still said 0.35. Snapping now happens only on release and always syncs back / 修复按下即对齐造成的"画布与数据不一致且无法撤销"
- ✅ **Duplicate rows fix / 列表重复行修复**: `all_units` was an alias of `units`, so newly created units were appended twice and appeared twice in the left list / 修复新建单位在左侧列表出现两行
- ✅ **Stale undo stack fix / 撤销栈清理**: "Clear all data" and "New tech tree" now clear the undo stack instead of allowing undos of units that no longer exist / 修复清空数据后仍能撤销出幽灵单位
- ✅ **Grid alignment fix / 网格错位修复**: The grid was always drawn from absolute origin (0,0) while the scene rect origin could be elsewhere, leaving parts of the canvas without grid or rulers when content was far from origin / 修复内容远离原点时网格与标尺错位
- ✅ **Faction detection fix / 阵营识别修复**: `units_sov_era1960.set` was parsed as faction `sov_era1960` (era treated as faction), producing wrong default export filenames. Now `sov` / 修复把时期当阵营导致默认导出文件名错误
- ✅ **Name collision check / 重名检查**: Creating a unit now also checks units that exist only in the research file / 新建单位重名检查现在也覆盖仅存在于 research 文件中的单位

### 🔧 Technical Improvements / 技术改进

The undo path runs these per-unit during multi-select drags, so this is a real hot path / 全部 41 处调试输出改为 DEBUG 短路（撤销路径在多选拖动时逐单位调用，属真实热路径）
